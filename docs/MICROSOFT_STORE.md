# Microsoft Store release gates

This is not a Store-ready product. The new build bundles Python and its native
AI engine, so it no longer requires consumers to install Ollama. It still needs
explicit first-use model downloads. Disclose their size, terms, internet use and
hardware requirements accurately.

Before selling: obtain a successful Windows build; test clean Windows 10/11
machines with no Python/Ollama; measure 16 GB performance; test offline behavior,
voice, screen consent and every action; audit dependencies/licenses; pin versions;
retain notices; implement required AI safety/reporting controls; obtain appropriate
code signing; choose an eligible Store packaging route; validate/certify the app.
No MSIX or signing certificate is supplied. The included Inno installer is unsigned.

Reserve JUPITAR in your Partner Center account and check relevant trademark rights.
No clearance has been performed. Supply real publisher identity, support email,
privacy URL, pricing, markets and accurate screenshots. Review donation-link and
transaction rules before retaining the PayPal link in a Store build. No payments
or entitlements are implemented. Original source remains MIT under the prior choice;
model terms are separate and require commercial review.
