# 0.3.0 scope

Implemented in source: embedded-engine lifecycle; authenticated loopback transport;
first-launch component wizard; checksum verification; custom identity/wake phrase;
local typed chat and Whisper small recognition; first-run mic consent and mute;
Windows SAPI output; basic energy-triggered interruption; HUD/system stats/orb;
approved memory/notes; reminders; optional hourly check-ins; one-shot screen
analysis; up to five allowlisted planned steps with approvals; supported app,
file, document, media, browser-search and mail-draft actions; confirmed cleanup.

No separate Ollama runtime is used. A successful Windows build bundles Python,
engine binaries and Rajdhani. Models download as data after explicit consent.
The engine is CPU-only by default, starts on demand and closes with the app.

NOT completed: Windows binary build, installer execution, clean-machine testing,
GPU configuration, natural neural multilingual TTS, robust echo cancellation,
dedicated low-power wake engine, universal mouse/browser automation, automatic
email sending, background screen watching, auto-start, embedded payments, signing,
MSIX, Store certification or a complete binary license/SBOM audit.

No movie-equivalent intelligence or universal task completion is claimed. Gujarati
quality is unmeasured. Cleanup only considers old top-level standard user Temp
files; it is not recursive system cleanup. Recycle Bin deletion is irreversible.
STOP prevents subsequent actions but cannot undo completed work. Reminders need
the app running. Wake matching is transcript-based, not a trained custom detector.
