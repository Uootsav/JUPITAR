JUPITAR 0.4 PREVIEW - ORBITAL UI + DOWNLOAD PROGRESS + WEBSITE

THIS IS SOURCE/BUILD CODE, NOT A COMPILED WINDOWS INSTALLER.
Nothing has been uploaded, built or published to your GitHub account by this chat.

QUICK VISUAL CHECK
Open ui/index.html in your browser. It is a VISUAL-ONLY preview, not the desktop
app. Open site/index.html to preview the website. Font fallback is expected until
Rajdhani is installed or downloaded by the build. Screenshots are in previews/.

UPDATE YOUR EXISTING REPOSITORY
1. Extract this ZIP. Upload the CONTENTS of its JUPITAR folder to your existing
   repository, replacing same-named files. Keep main.py and requirements.txt at root.
2. Replace .github/workflows/windows.yml with this version. Add pages.yml from
   that same workflow folder. Hidden folders may need manual file creation.
3. Run Build standalone Windows installer. It has NOT been run here.
4. If successful, download the installer artifact and test the new Windows app.

PUBLISH THE WEBSITE
Repository Settings > Pages > Build and deployment > Source: GitHub Actions.
Run Publish JUPITAR website in Actions. A successful deployment shows the site URL.

ALLOW PUBLIC DOWNLOADS
Test the installer first. Create/publish a GitHub Release and attach the EXE plus
SHA256.txt. The site enables Download only when it finds a public installer asset.
A private Actions artifact is NOT a public download. A draft release is NOT public.
