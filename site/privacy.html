Website privacy.

This static site includes no analytics, tracking pixels or account system added by this project. It requests public release metadata from GitHub’s API to find a published installer. GitHub Pages and GitHub API process network requests under their own policies. Following support links or downloading installers contacts the respective services.

Desktop app

The desktop preview processes AI locally after explicit model downloads. Microphone capture needs consent; screenshots are one-shot and consented. Approved memory and notes are plain text on the local Windows account. No audio recordings, chat history or screenshots are deliberately saved by the app. External browser and mail applications have their own network behavior.

This is a factual project summary, not a completed commercial privacy policy. Before a commercial release, the publisher must provide a real support contact, effective date and any required jurisdiction-specific disclosures.
